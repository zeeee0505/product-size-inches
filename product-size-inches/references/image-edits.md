# 图片标注脚本

从技能目录定位 `scripts/size_chart.py`。把下列占位路径换成实际路径，有空格或中文时保留参数引号。缺少 Pillow 时在本机可用的 Python 环境安装 `Pillow>=10.1`，例如 `python -m pip install "Pillow>=10.1"`。

```text
python -X utf8 "<skill>/scripts/size_chart.py" scan "<源目录>" "<独立工作目录>"
python -X utf8 "<skill>/scripts/size_chart.py" stage "<源目录>" "<edits.json>" "<独立工作目录>"
python -X utf8 "<skill>/scripts/size_chart.py" apply "<源目录>" "<独立工作目录>" "<原图备份.zip>"
python -X utf8 "<skill>/scripts/size_chart.py" export "<源目录>" "<独立工作目录>" "<转换结果.zip>"
```

每批使用独立工作目录，避免和旧缩略图混在一起。清单 `inventory.json` 的编号与 `scan-001.jpg` 等缩略图对应。支持单帧 JPEG、PNG 和 WebP；找不到或打不开的候选图单独报告。

UTF-8 的计划文件示例：

```json
{
  "images": [
    {
      "path": "套装/白底.jpg",
      "edits": [
        {"source": "22mm", "box": [650, 235, 785, 315], "height": 27, "layout": "stacked",
         "polygon": [[651, 253], [770, 253], [770, 296], [651, 296]]},
        {"source": "1.8cm", "box": [205, 140, 375, 250], "angle": -27, "height": 42,
         "polygon": [[207, 201], [349, 141], [371, 187], [229, 247]]},
        {"source": "72+5cm", "prefix": "Length:", "box": [450, 685, 790, 738]}
      ]
    }
  ]
}
```

- `path` 和可选的 `clean` 均是相对源目录的路径，统一用 `/`。可以处理多层文件夹和 Unicode 文件名。
- `box` 是图像显示方向上的像素坐标 `[左, 上, 右, 下]`，右和下不包含在框内。给旧字留几像素余量并避开箭头。用 `polygon` 时，各顶点都在框内，且只清理多边形内的底色。
- 默认 `layout: "inline"` 输出一行，例如 `2.2 cm / 0.9 in`。窄处设为 `"stacked"`，第一行显示 `2.2 cm /`，第二行显示 `0.9 in`。给新双标留出空间，使用 `polygon` 时只圈旧字；新字用 `box` 和 `center` 定位，预览其是否遮到尺寸线或商品。
- `angle` 以顺时针为正，朝右上用负角度。可选 `height` 是旋转前每行文字的目标像素高度；可选 `center` 是整个新标注的绝对中心坐标。需要匹配字体时给 `stage` 传 `--font "<本机字体文件>"`。
- 默认白底黑字，可用 `background` 和 `ink` 指定十六进制色值。若旧字覆盖原图细节，可用 `clean` 从尺寸、位置均对齐的无字图取相同区域。也可用 `background_patch` 引用工作目录里的局部无字补片，像素尺寸须恰好等于 `box` 的宽高。保留仅存在于原图的箭头或尺寸线。
- 数值支持 `cm`、`mm`、`厘米`、`公分`、`毫米` 及全角数字。厘米保留原数值，毫米精确换为厘米，英寸从未舍入的数值计算后保留一位小数。加号各项独立换算；无单位的项继承最后一项单位。若能核实旧图实际尺寸，同时记录 `source`（图上原值）、`confirmed_source`（经核实的公制值）及 `reason`。脚本不猜测 `m`、单独英寸、无单位数值或其他表达式的含义。
- `staged.json` 记录对应路径、目标标注、预览 PNG 和可交付的编码图。按表看预览，并打开编码图确认实际画质和排版。尝试复杂背景局部补片时按宿主允许的编辑工具重做该区域后重新核对；手工修改暂存文件会使校验失效，应按已审核的新计划重新生成。
- 源文件原位替换前先验证暂存及原图哈希，备份保留原图字节与子目录。任何源图或暂存图变更都需重新预览处理。覆盖失败时会尝试回滚已写文件；如需手工恢复，把 ZIP 中对应文件按相对路径还原到原目录。
- `export` 同样验证源图与暂存图，只把已处理的图片以原相对路径打包；不会把原图、预览和未处理的图片放进结果包，也不会写回输入目录。原图 ZIP 上传件应保留，用于需要时还原。
