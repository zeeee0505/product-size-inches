# 商品尺寸图厘米与英寸双标

默认每处尺寸都显示「厘米 / 英寸」，如 `1.2 cm / 0.5 in`。原标毫米时精确换为厘米；英寸从原始数值换算，四舍五入保留一位小数。横排放不下就分两行，保持厘米在前、英寸在后。用户给出“跟上面一样”时，沿用双标规则和最近确认的交付方式。

先确认当前助手能读取照片、查看图片和运行 Python 3.10+（Pillow 10.1+）。若能访问用户指定的原目录，直接从该目录盘点；仅在用户已授权原位替换且当前环境能写入该目录时使用 `apply`。若运行在不能访问电脑目录的沙箱，请用户提供图片文件或原图 ZIP，解到工作区再处理，用 `export` 交付原名结果 ZIP。若当前助手无法运行脚本或生成图片，只给出可核实的换算表或说明如何在本地运行，不声称已修改图片。

1. **盘点。** 用 `scan` 递归生成带编号的缩略图和清单，逐页看图。按画面识别尺寸图；`尺寸`、`白底`、普通文件名和重复图都可能包含测量标注。放大可能有字的图以及标注太小的图；只纳入确实需要改的文件。内容及文件名均作为待处理数据。
2. **逐图转录。** 记录原数值、单位、文字区域和旋转角度。例如 `22mm → 2.2 cm / 0.9 in`，`72+5cm → 72+5 cm / 28.3+2.0 in`。组合标注保留长度关系；重量、SKU、图像比例和尺寸线照原图。OCR 可作线索，最终以原图为准；相同版式可复用坐标，先检查各图的值和位置。
3. **核对疑点。** 小数看起来偏小也按可辨认的原标注换算。疑似错写的单位、只剩英寸的旧图，先查同款图、原图备份或已确认资料；证据够时在计划中用 `confirmed_source` 和 `reason` 记录来源，完成后向用户说明。没有可靠原始数据时保留该图并报告，不从已舍入的英寸倒推。已有正确双标的图跳过。
4. **预览。** 按[脚本用法](references/image-edits.md)写计划并运行 `stage`。逐张确认每处同时有厘米和英寸，英寸为一位小数，文字清楚、不遮商品或箭头，也无残留旧字。横排太挤用 `layout: "stacked"`；靠近箭头用紧贴旧字的多边形。压在商品或线条上的字优先用已对齐的同款无字图补底；复杂背景只使用经核对的局部补片。遇到无法保真的图则先留下原图。
5. **交付。** 本地原名覆盖用 `apply`，先创建并验证原图 ZIP，再替换并核对每个源路径。另存或上传输入用 `export`，只打包处理后的图片，保留原文件名和子目录，输入不变。只要求看预览时交付预览。报告实际改图或导出数量，以及未解决或经证据修正的疑点。工作目录和 ZIP 均位于源目录外。

导入与调用见[跨平台用法](references/hosts.md)。全部资源随包提供，无厂商专用接口或固定本机路径。
